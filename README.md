# NACEP policy agent

Everything needed to build the NACEP Accreditation Assistant in Copilot Studio.

- `GUIDE.md`: the full build guide. Start at section 2, "Build the agent".
- `agent/instructions.md`: the instructions to paste into Copilot Studio (retrieval date filled in as 2026-10-19).
- `sources/files/`: the 15 source files to upload as Knowledge, named exactly as the agent should cite them.
- `tests/gold.csv`: the 40-question test set.
